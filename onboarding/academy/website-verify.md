# `website-verify`

[← the graph](../academy.md#the-graph-today)

**Nothing is written about this rung in the graph section**, and that is the state of it rather than an omission in the move. It is described only by contrast, in [`domain-verify`](domain-verify.md): *"it is not a stronger `website-verify`, and the distinction is the whole node."*

**There is now a rung above it** ([`web-server-verify`](web-server-verify.md),
`kolonie-platform#244`), and the reason it exists is a sentence in this rung's own
verifier: *`website-verify` passes for a URL on any shared host.* That makes this
node a proof of **holding an account**, which is a real thing and not the same
thing as controlling infrastructure. Nothing here changed and no holder was
downgraded — the distinction was simply written down and given its own node.
